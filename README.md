#INFRAESTRUTURA DE REDE: RESIDÊNCIA E ESCRITÓRIO

##Sobre o projeto:
Este projeto foi desenvolvido no Draw.io como parte dos meus estudos de Redes de Computadores. Ele apresenta diagramas de infraestrutura de rede para dois cenários: um ambiente residencial e um pequeno escritório.

##Objetivo:
Representar a estrutura de conectividade de uma rede local (LAN), demonstrando como os equipamentos se conectam entre si e como acessam a Internet.

##Cenários desenvolvidos

###1. Rede domiciliar
Representação de uma rede residencial com conexões à internet, roteador, switch, ponto de acesso e dispositivos cabeados e sem fio.

###2. Rede de pequeno escritório
Representação de uma infraestrutura de rede para um pequeno escritório, com computadores, impressora, switch, roteador e ponto de acesso WI-FI.

##Conceitos aplicados
- Redes locais (LAN)
- Ethernet
- WI-FI
- Fibra óptica
- Roteadores e switches
- Ponto de acesso (AP)
- Conectividade com a Internet

Como melhoria futuras, o projeto poderá incluir documentação sobre segurança WI-FI com WPA2/WPA3, configuração de firewall, atualização de firmware e segmentação de rede. Também busco aprofundar meus conhecimentos sobre vulnerabilidades, controle de acesso e boas práticas de proteção de redes.
